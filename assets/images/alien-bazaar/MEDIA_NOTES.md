# Alien Bazaar website media notes

Place the photos and videos for the Autonomous Household Sorting Robot in this directory.

For each file, record:

- Original filename
- What is visible
- When in the build it was captured
- Which subsystem or problem it demonstrates
- Names of identifiable people and whether they may be named publicly
- Preferred caption, if any
- Whether it should be the timeline thumbnail, hero image, gallery image or video

The website page currently contains marked `data-media-slot="photos"` and `data-media-slot="videos"` sections so the final media can be inserted without restructuring the page.

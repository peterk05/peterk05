Reaction Wheel Inverted Pendulum

Modelled system dynamics in MATLAB/Simulink and implemented state-feedback control, achieving stable balancing for four seconds from a 10° initial offset.

Development process

01

Objective

Balance an inverted pendulum arm using a reaction wheel, connecting the physical system to a mathematical model and a control strategy.

02

First-principles modelling

Worked in a five-person team to derive the state-space model, simulate it in MATLAB and compare the simulation with physical hardware. The system used an IMU and a repurposed 24 V drill motor, without a custom PCB.

03

State-feedback control

Implemented a state-feedback controller using the system dynamics model developed in MATLAB/Simulink.

04

Measured result

Achieved stable balancing for four seconds from a 10° initial offset.
